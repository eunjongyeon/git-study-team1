## checklist

팀 저장소 1개, 팀원 4명 모두 Collaborator로 등록됨 o

team-chat.txt 에 팀원 4명 메시지가 최소 2바퀴 이상 이어져 있음

팀원별 브랜치 4개 생성 → review.md  작성 → main으로 merge 완료

stash → restore 과정 1회 이상 실습 및 기록

삽질 기록 팀원당 1개 이상 (총 4개 이상)
